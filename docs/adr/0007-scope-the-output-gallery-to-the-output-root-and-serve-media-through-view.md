# Scope the output gallery to the output root and serve media through `/view`

`LFGG_OutputGallery` lists only subfolders of the ComfyUI output directory, through one read-only pack route that returns descriptors, and every image, video, and audio byte is served by ComfyUI's native `/view` route with `type=output`. We rejected arbitrary absolute paths because `/view` refuses anything outside the input, output, and temp directories, so supporting them would make the pack serve raw file bytes itself behind a `config.json` root allowlist, with its own containment, symlink, content-type, and size checks on an unauthenticated route. The stated problem, finding earlier generations without opening the output folder, lives entirely under the output root, so the restriction costs nothing today and keeps the pack's filesystem surface to a bounded directory walk and `stat`. The node is also kept out of execution entirely: it has no outputs, is not an output node, and refreshes from queue events on the frontend, because a listing that needs a queue run would reproduce the problem it exists to solve. The cost is that a gallery for another drive or a shared network folder needs a separate design with a file-serving route, and that image tiles pay full pixel dimensions at reduced quality because `/view`'s `preview` parameter re-encodes without resizing.
